# Cinematic Counter-Cartographies

## Overview
Cinematic Counter-Cartographies is a project that explores the intersection of cinema and spatial politics. This project aims to provide a comprehensive archive of terms, concepts, and analyses related to cinematic representations of space, surveillance, and political narratives.

## Project Structure
The project is organized into the following main directories and files:

- **css/**: Contains stylesheets for the project.
  - `style.css`: Shared styles for the project.
  - `mobile.css`: Mobile-specific styles for responsive design.

- **js/**: Contains JavaScript files for functionality.
  - `shared.js`: Shared JavaScript functionality across multiple pages.
  - `glossary.js`: JavaScript specific to the glossary page.

- **partials/**: Contains reusable HTML components.
  - `mobile-nav.html`: HTML structure for the mobile navigation overlay.

- **HTML Files**:
  - `index.html`: Homepage of the project.
  - `glossary.html`: Glossary page with terms and definitions.
  - `map.html`: Map feature layout and functionality.
  - `analysis.html`: Page for visual analysis of films.
  - `about.html`: Information about the project and contributors.
  - `privacy.html`: Privacy policy outlining data handling.
  - `terms.html`: Terms of use for the project.

## Features
- **Glossary**: A comprehensive glossary of terms related to cinematic counter-cartographies, allowing users to search and filter terms.
- **Responsive Design**: The project is designed to be fully responsive, providing an optimal viewing experience on both desktop and mobile devices.
- **Interactive Elements**: JavaScript functionality enhances user interaction, including search and filter capabilities on the glossary page.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cinematic-counter-cartographies
   ```
3. Open `index.html` in a web browser to view the project.

## Usage Guidelines
- Explore the glossary to understand key terms and concepts.
- Use the navigation menu to access different sections of the project.
- Ensure to review the privacy policy and terms of use for guidelines on data handling and user responsibilities.
